# SO-101 Robotics & AI Portfolio

A static portfolio website for Amani Njiru.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — colours, fonts, layout and responsive styling
- `script.js` — small JavaScript enhancement

## Preview locally
Open `index.html` in a browser. For a better local development workflow, open this folder in VS Code and use the Live Server extension.

## Edit the website
- Change text and links in `index.html`.
- Change the colour palette and typography at the top of `style.css` in the `:root` block.
- The two YouTube video URLs are in the `iframe src` and matching `Watch on YouTube` links in `index.html`.

## Publish
Upload the contents of this folder (not the outer folder itself) to a static host such as Netlify Drop. Ensure `index.html`, `style.css`, and `script.js` remain together in the published root.

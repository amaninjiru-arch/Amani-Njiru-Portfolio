Project overview

Teaching robots through human demonstrations

This project explores how a robotic system can move from direct human control toward learning tasks from human demonstrations. Using a pair of SO-101 robotic arms and the LeRobot software environment, the work is organised around teleoperation, demonstration data collection and imitation learning.

The work combines practical hardware setup with software configuration and an investigation into how visual observations, robot states and actions can be used to train a robot policy.

01 / Completed milestone

Teleoperation and robotic control

I configured the software environment, calibrated the leader arm and established communication between the leader and follower arms. Calibration defined the relationship between the arm's joint positions and movement limits, helping the system translate human-guided motion into commands for the follower.

The leader arm acts as the human-controlled interface. As it is moved, the system captures its joint positions and sends corresponding commands to the follower arm. After testing and adjustments, I achieved real-time mirroring of the leader arm's movements by the follower.

Outcome: a functioning leader–follower teleoperation system.

02 / In development

Demonstration data collection

The next stage is to build a data-collection workflow that records demonstrations alongside observations of the robot and its environment. I am setting up an external camera so that recorded examples can combine visual scenes, robot states and actions.

The intended dataset will capture repeated demonstrations of simple manipulation tasks, such as reaching for an object, grasping it and placing it at a target location. I am paying particular attention to consistency, recording quality and variation between demonstrations.

03 / Planned next stage

Imitation learning

Once a usable demonstration dataset has been collected, I plan to train an imitation-learning policy. A policy is a model that maps observations and robot state to an action. Rather than manually guiding every movement, the goal is for the follower arm to use a trained policy to perform a demonstrated task.

Initial experiments will focus on simple, measurable tasks such as reaching, grasping and object placement. I also want to evaluate how the policy responds to imperfect demonstrations, small changes in object position and variations in the environment.

04 / Exploration

Lightweight AI for robotics

I am interested in exploring smaller, computationally efficient models for focused robotic tasks. The aim is to understand how visual observations and robot states can be mapped to actions while balancing model performance, inference requirements and available computing resources.

This direction will help me build a practical understanding of model training, inference and evaluation, and investigate how capable robotic learning systems can be developed without depending immediately on expensive computing infrastructure.

Project direction

From control to autonomy

My longer-term objective is to develop a robotic system that can learn practical tasks from human demonstrations and execute them with increasing autonomy. This project is helping me build experience across robotics, machine learning, computer vision and the practical application of AI.
